# Project development instructions

- The product UI is migrating from Python to Electron. All new UI work and UI improvements must target `apps/desktop` (Electron/React).
- Do not develop, extend, or redesign the legacy Python UI. Python backend/service changes needed by Electron are allowed.
- Treat GitGod as a development tool inside the coding agent workspace, sharing the selected project and coding workflow.
- Preserve existing uncommitted changes when implementing new work.
